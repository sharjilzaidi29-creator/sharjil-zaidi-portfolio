# Sharjil Zaidi — Cloud & DevOps Engineer Portfolio

A cinematic React + Vite + Tailwind portfolio customized for Sharjil Zaidi.

## Included
- Sharjil profile image
- Downloadable resume
- Azure / DevOps focused skills
- Two real projects with GitHub links
- Education and certifications
- GitHub, LinkedIn, Instagram, email and phone links
- Responsive mobile layout
- GitHub Pages deployment workflow

## Local development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The repository includes `.github/workflows/deploy.yml`. Push the project to the `main` branch and the workflow builds and deploys the `dist` folder to GitHub Pages. If GitHub asks for a Pages source, choose **GitHub Actions**.
